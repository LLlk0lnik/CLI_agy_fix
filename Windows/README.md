# agyCLI — Windows 10/11 x64 (Intel/AMD, 64 бита)

Переносимый запуск обычного Antigravity CLI через собственный локальный шлюз и отдельную авторизацию. Запасной ACP-клиент также включён. Это не официальный дистрибутив Google; оригинальные бинарники Google не изменены.

```text
README.md
agym.cmd      — единая CLI-команда со всеми флагами и шорткатами
Run-AGY.cmd   — обычный CLI через VPN/шлюз
Run-ACP.cmd   — отдельный ACP-клиент
setup/        — Login и Check
app/          — код, runtime, config и локальный профиль
docs/         — README-AI и сведения о компонентах
```

## Быстрый старт с `agym.cmd`

```cmd
:: 1. Проверить работу Happ и окружения
agym.cmd check

:: 2. Войти в Google-аккаунт через браузер
agym.cmd login

:: 3. Запустить в текущей папке проекта
agym.cmd

:: Или запустить без лишних запросов подтверждений прав (yolo-режим):
agym.cmd -y
```

## Установка с самого начала

### 1. Получить agy — Antigravity CLI

Официальная инструкция и скачивание: [Google Antigravity](https://antigravity.google/docs/getting-started).
В этом архиве **agy 1.4.12 уже скачан** и находится в `app/runtime/agy.exe`. Поэтому для этой сборки отдельная установка CLI не нужна: используются именно вложенные бинарники, независимо от установленного в системе agy.

Если нужен и обычный системный agy, его официальный установщик запускается так:

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

Это необязательный шаг и он может добавить agy в системное окружение пользователя. Наши запуски не вызывают установщик и не меняют PATH. Команда просто `agy` запустит обычную установленную версию, а `agym` — эту модифицированную сборку через Happ.

### 2. Установить Python

Скачайте Python 3.11 или новее с [python.org](https://www.python.org/downloads/). Сторонние Python-пакеты и pip install не нужны.
При установке включите Python Launcher (команда py). Если установлен только python.exe, CMD-запуски попробуют его автоматически. Если Windows открывает Microsoft Store вместо Python, установите Python с python.org и включите launcher.

Проверьте:

```cmd
py -3 --version
```

### 3. Установить и настроить Happ

Скачайте Happ с [happ.info](https://happ.info/) и добавьте свою рабочую конфигурацию или подписку. В настройках Happ найдите входящие локальные порты.

Откройте `app\config.json` и при необходимости укажите ваши реальные порты Happ:

```json
{
  "http_proxy": "http://127.0.0.1:10809",
  "socks_proxy": "socks5h://127.0.0.1:10808",
  "default_model": "gemini-3.8-flash-high"
}
```

Адреса должны оставаться локальными (`127.0.0.1`), без паролей в этом файле.

### 4. Проверить установку и сеть

```cmd
agym.cmd check
:: или setup\Check.cmd
```

### 5. Войти под своим аккаунтом Google

```cmd
agym.cmd login
:: или setup\Login.cmd
```

Завершите вход в открывшемся браузере и дождитесь «Вход завершён».

### 6. Запуск и флаги `agym.cmd`

```cmd
:: Интерактивный диалог в текущей папке
agym.cmd

:: Режим авто-одобрения без подтверждений
agym.cmd -y
agym.cmd yolo

:: Одиночный запрос
agym.cmd -p "Ответь одним словом: привет"

:: Продолжить предыдущий разговор
agym.cmd -c

:: Текстовый ACP-клиент
agym.cmd acp
```

## Что запускает каждый файл

| Файл / Команда | Назначение |
| --- | --- |
| `agym.cmd` | Единая CLI-команда со всеми флагами (`-y`, `yolo`, `login`, `check`, `acp`) |
| `Run-AGY.cmd` | Штатный интерфейс agy CLI через отдельный локальный шлюз |
| `Run-ACP.cmd` | Простой текстовый клиент официального ACP-агента |
| `setup\Login.cmd` | Только отдельная браузерная авторизация |
| `setup\Check.cmd` | Проверка зависимостей, прокси и доступности профиля |

## Где данные и что изолировано

Папка `app\profile` появляется только после первого использования. Авторизация ACP: `app\profile\gemini\antigravity-acp`. История и настройки штатного CLI: `app\profile\native-home`. Диагностика ACP: `app\profile\server.log`.

Настройки окружения действуют только в процессе запуска и его потомках.

## FAQ

### Нужно ли иметь `agy` на машине изначально?
**Нет, не нужно.**
Официальный бинарник `agy.exe` (1.4.12) уже находится в `app\runtime\agy.exe`. Скрипт `agym.cmd` обращается напрямую к нему.

### Можно ли запускать `agym.cmd` из любой папки проекта?
**Да.**
Добавьте путь к папке `Windows` в системную переменную `PATH` (или поместите `agym.cmd` в каталог из `PATH`). После этого можно вызывать `agym` из любой рабочей папки проекта.
